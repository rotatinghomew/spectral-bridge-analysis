# 薄膜分光测量资料交换

`data/` 收录供演练使用的合成记录，不含真实企业或人员资料。资料使用 UTF-8 逗号分隔，首行为字段名，带逗号的单值用双引号括起。日期采用 ISO 表示，空字段表示来源未填或不适用，不代表数值零。`sources.json` 记录各表列名、身份键和可直接核对的引用。

## 业务资料

- `instruments.csv`：读头及实际使用区间，读值单位为归一化透过率百分点。
- `slices.csv`：检件与母片归属，互换组以明确记录为准，空值表示未确认。
- `readings.csv`：读头原始读数；同片可有重复读数。以记录时刻 received 作为可见时点，day 为测量日。
- `pair_changes.csv`：互换声明更正。撤销只能使该检件与其他检件之间的互换失效，不取消读数。
- `orders.csv`：R0 尺度验收边界含端点；line_only=1 时只接收产线取样，lab_allowed=1 时可使用同卷复测。
- `certificates.csv`：证书覆盖的卷材，以逗号分隔。group_max_mean_error 是订单允许的组级均值偏移上界；common_reader_bias 标示同读头偏移不能独立抵消。
- `retests.csv`：复测申请按物理片、设备及时段识别；同一卷同规格的订单可引用同一批留样。

所有日期是业务所在地日历日，生效区间为左闭右开。已退回的互换声明不会删去原始读数。空白发运日表示未确认发运；误差上界和读值都在 R0 标度上。

## 本地核对

需要 Python 3.11。分析环境可使用 `python3 -m pip install -r requirements.txt` 安装锁定的数值依赖。

从仓库根目录执行 `python3 check_sources.py`，返回各表行数；其他同格式资料可用 `python3 check_sources.py 路径` 检查。脚本只读资料并报告结构或引用错误，不给出业务结论。执行 `python3 -m unittest discover -s tests -v` 检查资料约定及拒绝重复身份的行为。

## 跨尺度可比较性与出货判定（`filmqc/`）

`filmqc` 只依赖标准库，把上述资料按业务规则落成可复核的判定，核心约定：

- **证据单位是物理片**：同一检件重复读数先平均为一个检件级数值；两台读头的读数只有在“同检件直读”或“同物理片且互换组记录在判断时点仍有效”时才允许配对。`pair_changes` 的撤销只禁止后续配对，从不删除读数，也不撤销原本合法的直读。
- **换算关系随读头、系列、测量区间生效**：线性最小二乘只在 `purpose=fit` 的物理片上拟合，`purpose=holdout` 的独立标准片用于误差验证，两者严格不重叠；拟合区间外的读数判为外推并拒绝，相邻型号不借关系。拟合片少于 2 片或没有独立留出片的关系标记为不支持（如旧读头 R1）。
- **可比较性看独立标准片与允许总误差，不看拟合优度**：直连路线的证据误差是留出片最大绝对残差；经两次换算时，同一张标准片在两段都出现只计一份独立证据，误差按同号叠加（不假设相互抵消）。
- **争议显式化**：同一卷材上两条有数据支持的路线若在材料判定或订单允许总误差上结论不一致，判 `dispute` 并附主要误差来源，禁止默认挑较有利路线放行。
- **采样许可**：`line_only=1` 不接收质控室 R0 复测，但产线读头换算后的结果仍属产线证据；`lab_allowed=1` 才接受同卷 R0 复测。
- **证书组级验收**：`common_reader_bias=1` 下整组按共享偏移的误差均值与 `group_max_mean_error` 比较，不允许逐卷误差独立平均；逐卷可用不等于整组可用。仅 `partial_allowed=1` 才给出满足组界的部分交付子集，客户要求整组核验的测量不拆散。
- **复测工作台**：区分卷材取样（只覆盖该采样许可下的同卷订单待办）与标准片补证（只恢复证书的共同换算路径，不冒充实际取样）；未完成的相同 `(检件, 读头)` 申请按重复占位拒绝；已完成但读数未进入 `readings.csv` 的复测不产生新证据。
- **已交付证书冻结**：签发后的互换撤销等变化只生成影响说明与卷宗差异，不回写采用的读数和判断；卷宗沿证书可追溯每卷直读、适用关系方程、拟合/留出片集与等待中的复测。

命令：

```bash
python3 -m filmqc.report                 # 中文文字报告，默认判断时点 2026-04-10
python3 -m filmqc.report --as-of 2026-04-06
python3 -m filmqc.report --json          # 机器可读 JSON（含完整卷宗）
```

`python3 -m unittest discover -s tests -v` 同时覆盖资料约定与上述业务规则（配对/撤销、拟合与留出分区、两次换算不重复计证据、外推拒绝、争议挂起、采样许可、组级共享偏移、部分交付、冻结证书、复测工作台）。
